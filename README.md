# 🎮 Bryansk_game — Платформа цифровой дистрибуции компьютерных игр (Full-Stack Steam Clone)

**Bryansk_game** — это интернет-магазин и веб-платформа для ПК-геймеров, концептуально вдохновленная Steam и современными интерфейсами игровых магазинов.
(САЙТ ЯВЛЯЕТЬСЯ ОБЛОЖКОЙ, НА НЁМ НЕТ РЕАЛЬНЫХ ИГР И СВЯЗИ С ГУГЛ, можно регистрировать аккаунт под выдуманной почтой).
---

## 🌟 Ключевые возможности

### 1. 🎨 Дизайн и Темы оформления (4 темы)
- **Тёмная (Dark Obsidian)**: Классический глубокий темный стиль с синими акцентами.
- **Светлая (Clean White)**: Минималистичный белый дизайн с красными кнопками-акцентами (по референсу 1).
- **Красная (Crimson Gaming)**: Агрессивная рубиновая геймерская эстетика.
- **Фиолетовая (Cyberpunk Neon)**: Неоновый пурпурный интерфейс (по референсу 2).
- **Плавные 3D-анимации**: Иконки и карточки игр плавно приподнимаются и выдвигаются на передний план при наведении (`game-card-hover`).

### 2. 🌍 Мультиязычность и Мультивалютность
- **Языки**: Русский (по умолчанию) и English с мгновенным переключением в шапке и настройках.
- **Валюты**: Рубли (₽) и Доллары ($).
- **Встроенный Кошелёк (Wallet)**: Переключение отображения цен магазина непосредственно внутри кошелька или в шапке в один клик.

### 3. 💳 Платёжные системы и оформление заказа
- **СБП (QR-код)**: Оплата через Систему быстрых платежей РФ по динамическому QR-коду для банковских приложений.
- **Банковские карты**: Visa, Mastercard.
- **USDT (Криптовалюта)**: Оплата Tether USDT в сети TRC-20 с копированием адреса кошелька.
- **Баланс Кошелька**: Мгновенная покупка игр в 1 клик с баланса аккаунта.

### 4. 🕹️ Каталог и Страница игры
- **Умный поиск**: С фильтрами прямо в поисковой строке и категориями (Action, RPG, Strategy, Competitive, Tactical, Cyberpunk, Racing, Souls-like).
- **Интерактивный Hero-баннер**: С выбором версий, рейтингом и просмотром трейлеров.
- **Специальные предложения**: Блок скидок и горячих новинок.
- **Системные требования**: Минимальные и рекомендуемые характеристики для каждого тайтла.
- **Отзывы игроков**: Оценки и отзывы пользователей, купивших игру.

### 5. 📚 Библиотека игр (Steam-style)
- Отображение всех приобретенных игр с обложками.
- Симуляция запуска игр и установки на диск.
- Трекер наигранного времени и повышение уровня аккаунта.
- Достижения Steam / Bryansk_game.

### 6. 👤 Профиль пользователя и Социальные функции
- Профиль в стиле Steam с уровнем, значками («Первопроходец Брянска», «Коллекционер», «Хардкорный геймер») и витриной любимых игр.
- Список друзей с отображением статусов: *«В игре»*, *«В сети»*, *«Не в сети»*.
- Симуляция диалогов и чата в реальном времени.
- Возможность обратиться в поддержку в случае неполадок (тест функция).

### 7. 🛡️ Роли и Админ-панель
- Роли: `USER`, `ADMIN`, `PUBLISHER`.
- Панель управления: Добавление новых игр, редактирование цен и скидок, удаление из каталога, бан игрока.
- Сброс макета - сбрасывает все функции к начальной точке.

---

## 🛠️ Стек технологий

- **Frontend**: React 18, Tailwind CSS, Lucide Icons, Canvas Confetti, Vite.
- **Backend**: Node.js, Express.js REST API.
- **База данных**: SQLite (с автоматическим созданием таблиц и сидированием данных) + Prisma Schema.
- **Аутентификация**: JWT (JSON Web Tokens) + Bcrypt.

## 🚀 Инструкция по запуску

### 1. Как запустить сайт БЕЗ бэкенд-сервера (только клиентская часть)

Если у вас на руках только папка с проектом и вы хотите быстро открыть и продемонстрировать внешний вид сайта, дизайн, темы оформления, анимации и интерфейс без поднятия Node.js бэкенда и базы данных SQLite:

#### Что нужно иметь на компьютере:
- **Node.js** (версии 18 или новее) — скачивается бесплатно с официального сайта [nodejs.org](https://nodejs.org/).

---

#### Способ 1: Стандартный запуск через встроенный Dev-сервер Vite (Самый простой)

1. **Откройте терминал** (PowerShell, Командную строку CMD или терминал в VS Code) в корневой папке проекта:
   ```bash
   cd "C:\Users\Никита\OneDrive\Рабочий стол\Пробник\client"
   ```
2. **Установите зависимости** (выполняется один раз, скачивает все нужные библиотеки в `node_modules`):
   ```bash
   npm install
   ```
3. **Запустите сайт**:
   ```bash
   npm run dev
   ```
4. **Откройте браузер**:
   В терминале появится локальная ссылка, например:
   👉 **`http://localhost:5173/`** (зажмите `Ctrl` и кликните по ссылке или вставьте в строку браузера).

> [!NOTE]
> **Что работает в режиме без бэкенда:**
> - Весь адаптивный интерфейс и вёрстка.
> - Мгновенное переключение всех **4 тем оформления** (Dark Obsidian, Clean White, Crimson Gaming, Cyberpunk Neon).
> - Переключение языков (**Русский / English**).
> - Переключение валют (**₽ / $**).
> - Интерактивные 3D карточки игр, баннеры, модальные окна, корзина и визуальные эффекты.

---

#### Способ 2: Запуск собранной статической версии (Production Preview)

Если вам нужно собрать проект в чистый статический HTML/JS/CSS и запустить локальный просмотр:

1. Перейдите в папку `client` и соберите билд:
   ```bash
   cd client
   npm install
   npm run build
   ```
   *(Команда создаст автономную папку `client/dist` со скомпилированными файлами).*
2. Запустите встроенный легковесный предпросмотр:
   ```bash
   npm run preview
   ```
   Или используйте одноразовый утилитный сервер:
   ```bash
   npx serve dist
   ```
3. Перейдите по адресу, указанному в консоли (обычно `http://localhost:4173`).

---

#### Способ 3: Запуск через расширение Live Server в VS Code (Без командной строки)

1. Выполните сборку: `npm --prefix client run build`.
2. В редакторе VS Code найдите файл `client/dist/index.html`.
3. Нажмите по нему правой кнопкой мыши и выберите **"Open with Live Server"**.

---

### 2. Полный запуск (Frontend + Backend + База данных)
